## 👋 About This Repository

Hi! I am a **BSIT 3rd semester** student at the **University of Okara**.

This repository is my **daily DSA diary**. Every day I upload:

- 💻 The code I wrote
- 📝 Short notes in my own words
- ✅ Practice tasks and their solutions

**My goal:** Understand DSA, write the code myself, and explain it in viva.
